# The Worst Possible AI Server
An ongoing project to figure out how to build a cheap, low-end LLM inference server from used parts. For a lot of people, there's a decent chunk of their day-to-day use of AI services that aren't too complex - simple search questions, or conversations to work through ideas. These use cases don't need giant, hyper-capable models run by big tech companies; a modest local server should be more than capable of handling them. The Worst Possible AI Server is an example of such a server.
